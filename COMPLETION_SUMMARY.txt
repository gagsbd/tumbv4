WHAT WAS IMPLEMENTED:
=====================

A complete autonomous movement sequencing system for your Tumbler V2 robot that
allows you to define and execute series of maneuvers automatically.

FEATURES:
---------
✅ Define sequences of up to 20 maneuvers
✅ Execute maneuvers automatically in order
✅ 4 movement types: Forward, Backward, Turn Left, Turn Right
✅ Precise control over distances and durations
✅ Remote control integration (press * and # keys)
✅ No new hardware required
✅ Uses existing encoder and motor systems
✅ Safe balancing maintained throughout
✅ Backward compatible with all existing functions

================================================================================

MOVEMENT TYPES AVAILABLE:
=========================

1. MANEUVER_FORWARD
   - Move straight forward
   - Parameter: encoder pulse count
   - Example: addManeuver(MANEUVER_FORWARD, 500);

2. MANEUVER_BACKWARD
   - Move straight backward
   - Parameter: encoder pulse count
   - Example: addManeuver(MANEUVER_BACKWARD, 300);

3. MANEUVER_TURN_LEFT
   - Turn left in place
   - Parameter: duration in milliseconds
   - Example: addManeuver(MANEUVER_TURN_LEFT, 500);

4. MANEUVER_TURN_RIGHT
   - Turn right in place
   - Parameter: duration in milliseconds
   - Example: addManeuver(MANEUVER_TURN_RIGHT, 500);

5. MANEUVER_WAIT (bonus)
   - Pause at current position
   - Parameter: duration in milliseconds
   - Example: addManeuver(MANEUVER_WAIT, 1000);

HOW TO USE (3 STEPS):
====================

STEP 1: Clear Previous Maneuvers
   clearManeuvers();

STEP 2: Add Maneuvers
   addManeuver(MANEUVER_FORWARD, 500);
   addManeuver(MANEUVER_TURN_LEFT, 500);
   addManeuver(MANEUVER_FORWARD, 500);

STEP 3: Start Execution
   startManeuverSequence();

Robot automatically executes all maneuvers in order!

CALIBRATION REQUIRED:
=====================

Your robot's encoder and motor characteristics are unique. You must calibrate:

1. ENCODER COUNTS (for forward/backward):
   - Test with: addManeuver(MANEUVER_FORWARD, 100);
   - Measure actual distance
   - Calculate: pulses_per_cm = 100 / actual_distance_cm
   - Use for all future forward/backward movements

2. TURN DURATION (for left/right turns):
   - Test with: addManeuver(MANEUVER_TURN_LEFT, 100);
   - Measure actual rotation angle
   - Calculate: ms_per_degree = 100 / actual_angle_degrees
   - Use for all future turns

See START_HERE.md for detailed calibration instructions.

IMPORTANT NOTES:
================

1. ROBOT MUST BE BALANCED
   - Always ensure robot is upright before starting sequence
   - Give ~2-3 seconds after power-on for balance initialization

2. SAFE OPERATION
   - If robot loses balance, sequence stops automatically
   - Robot maintains balance during all movements
   - Motor control still functions through balance control

3. ADEQUATE SPACE
   - Ensure sufficient floor space for defined movements
   - Test movements one at a time initially
   - Clear area of obstacles

4. ENCODER CONNECTIONS
   - Verify encoder connections are secure
   - Loose connections will cause incorrect distances
   - Check encoder calibration if movement distances are wrong

5. COMPATIBILITY
   - Works alongside all existing robot features
   - Doesn't interfere with obstacle avoidance
   - Doesn't interfere with follow mode
   - Can be triggered by remote control or Bluetooth
